# Security Policy

SI is an early development project. There are no supported stable releases yet; fixes are developed on `main`.

An input method handles potentially sensitive text. Do not include passwords, private messages, real customer data, or unredacted composition logs in reports.

If the repository offers private vulnerability reporting, use the **Report a vulnerability** option in its GitHub Security tab. If it is unavailable, open an issue asking for a private reporting channel without disclosing exploit details or sensitive data.

Please include affected revisions, a minimal reproduction using synthetic input, impact, and any proposed fix. Ordinary typing bugs belong in the issue tracker.
